# Family Cleaning Solution

Sitio estático listo para publicar en GitHub Pages.

## Estructura

- `index.html`: página principal.
- `styles.css`: estilos del sitio.
- `script.js`: comportamiento del formulario de contacto estático.
- `assets/`: imágenes, logo y recursos visuales.
- `.nojekyll`: evita procesamiento de Jekyll en GitHub Pages.

## Publicar en GitHub Pages

1. Sube estos archivos al repositorio.
2. En GitHub, ve a `Settings` > `Pages`.
3. En `Build and deployment`, selecciona `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda los cambios.

El archivo principal ya es `index.html`, así que GitHub Pages lo usará como página inicial.
